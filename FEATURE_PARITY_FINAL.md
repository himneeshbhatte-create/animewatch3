# AnimeVault final native parity

The uploaded AnimeVault web application was used as the functional reference.

## Normal area
- Home
- Continue Watching
- Popular
- Discover/Search
- Filters: genre, format, status, sort, year
- Posters, score and progress
- Schedule with daily navigation
- Watchlist / Completed / Favorites / Ongoing
- Anime detail sheet
- Poster zoom
- Watching / Completed / Plan / Favourite
- Watch next / Mark next / Mark through / episode jump
- 100-episode paging
- External watch provider picker
- Exact AniList episode links when supplied
- Persistent eight provider slots
- Return-and-mark-watched flow
- Dashboard and exports

## Mature area
- Separate browse
- Separate schedule
- Watching
- Completed
- Adult titles excluded from normal Discover
- 18+ provider confirmation gate

## Persistence
- Library
- Favorites
- Provider URLs
- Mature/streaming settings
- 18+ confirmation
- JSON backup/restore
